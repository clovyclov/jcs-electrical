Common Questions

Lighting & Outlet Installation FAQ

How much does it cost to install recessed lighting? +
Cost depends on the number of fixtures, ceiling access (open joists vs. finished drywall), and whether new switch wiring is needed. We give an exact, upfront flat-rate quote before any work starts — no hourly surprises.
Do my kitchen and bathroom outlets need to be GFCI? +
Yes — current electrical code requires GFCI (ground-fault) protection on outlets in kitchens, bathrooms, garages, and outdoor areas. If your home still has older two-prong or non-GFCI outlets in these spaces, we can upgrade them to bring your home up to code.
Can you install a ceiling fan where a light fixture used to be? +
Usually, yes — but standard light fixture boxes aren't always rated to support a fan's weight and vibration. We check the existing box and swap in a properly rated, braced fan box when needed so it's installed safely.
Do you handle municipal electrical permits and inspections? +
Yes, 100%. As licensed, bonded, and insured WA electrical contractors (License # JCSECEL760DM), we pull all necessary city/county electrical permits and schedule inspector sign-offs so your installation is completely safe and code-compliant.
